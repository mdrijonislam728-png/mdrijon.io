# MD Rijon Islam — Cybersecurity Portfolio

A modern, light, animated, responsive portfolio built with plain HTML/CSS/JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — design, responsive layout, glassmorphism, animations
- `script.js` — mobile navigation, scroll reveal, animated particle background

## GitHub Pages deployment

1. Create a new GitHub repository, for example: `rijon-portfolio`
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.
6. GitHub will publish the website at your Pages URL.

## Edit your content
Open `index.html` and update the text in the Hero/About/Skills sections whenever you gain new certifications, projects, or experience.
